## Projects

### [`embedded-ring-buffer-library`](https://github.com/mohamedAziz-bousbih/embedded-ring-buffer-library)
Portable, interrupt-safe ring buffer in C. Designed for embedded targets where dynamic allocation is not an option. Includes a host-side test harness that runs without hardware.

### [`uart-frame-parser`](https://github.com/mohamedAziz-bousbih/uart-frame-parser)
UART frame parser in C with start/stop delimiters, CRC-8 checksum validation, and escape byte support. Includes a Python test sender and reference decoder.

### [`smart-medical-card-emulator`](https://github.com/mohamedAziz-bousbih/Smart-medical-card-emulator)
Role-based smart card emulator in Python. Simulates chip-based patient record access with AES-256-GCM encryption and per-role read/write permissions (Doctor, EMT, Pharmacist).

### [`Agri-Cows.App`](https://github.com/mohamedAziz-bousbih/Agri-Cows.App)
Cattle farm management REST API and PWA. Flask + SQLAlchemy backend with blueprints, Marshmallow schemas, Alembic migrations, and JWT authentication.
